Resume and Bio-Data Website

A simple and responsive personal website developed using HTML, CSS, JavaScript, and jQuery. This project showcases a student's resume and bio-data through a clean layout with interactive elements.

Features

- Resume Page: Displays career objective, educational qualifications, technical skills, projects, and strengths.
- Bio-Data Page: Presents personal information, education details, languages, and hobbies.
- Responsive Design: Uses CSS styling for a clean and organized appearance.
- Interactive Button: Displays a thank-you message when clicked.
- JavaScript Functionality: Displays the website loading date in the browser console.
- jQuery Effects: Adds fade-in animation and heading color changes on mouse hover.
- Navigation: Allows users to switch between the Resume and Bio-Data pages.

Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery

Project Structure

- "index.html" – Resume page
- "biodata.html" – Bio-data page
- "style.css" – Website styling
- "script.js" – JavaScript and jQuery functionality

How to Run

1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Open "index.html" in a web browser.
4. Navigate between the Resume and Bio-Data pages to explore the website.

Objective

The objective of this project is to demonstrate basic web development skills, including webpage design, styling, navigation, and interactive functionality using JavaScript and jQuery.
